# Laboratorio Shuri (solo gli strumenti)

Qui ci sono gli script e le istruzioni di Shuri, l'agente del prof che sul Mac prova ogni versione nel simulatore
(`batteria.py`) e analizza le scatole nere vere (`analizza_scatola.py`). Trovano da soli le cartelle `ClaudeRob_V*`,
`ClaudeRob_Simulatore_V*` e `ScatoleNere` accanto a questa cartella.

NON sono su GitHub (restano sul Mac): `Prove/` (170 MB di risultati delle batterie), `Confronti/`, le copie di sicurezza
`*_prima_del_*`. `SHURI_rapporto.md` e `SHURI_scheda_correzioni.md` sono l'ultimo rapporto (5/11 sera, sulla V37).

Uso: `python3 batteria.py ../ClaudeRob_V39` (circa 16 gare; risultati in `Prove/`, rapporto in `SHURI_rapporto.md`).
